# MZT Academic Website

This repository contains a simple one-page academic website for GitHub Pages.

The site is intentionally built with plain HTML and CSS. It does not depend on
any external theme, package manager, or build system.

## Edit Content

- Edit `index.html` to update the CV, contact information, and publications.
- Edit `styles.css` to adjust visual design.
